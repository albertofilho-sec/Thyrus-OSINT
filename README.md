<h1 align="center">🛡️ Thyrus OSINT & Attack Surface Framework</h1>

<p align="center">
Framework multiplataforma voltado para automação de processos de reconhecimento defensivo, auditoria passiva e Attack Surface Management (ASM).
</p>

---

## 🚀 Objetivo do Projeto

O **Thyrus** foi desenvolvido com foco em:

- OSINT defensivo
- Attack Surface Management (ASM)
- Auditoria Passiva de Exposição Pública
- Validação de Conformidade
- Automação de Reconhecimento Defensivo
- Apoio Operacional para Equipes Blue Team

A solução centraliza ferramentas amplamente utilizadas em processos de análise de superfície de ataque e exposição pública de infraestrutura.

## 🧩 Ferramentas Integradas

| Categoria | Ferramenta | Objetivo |
|---|---|---|
| Identidades | Sherlock | Análise de presença pública |
| Identidades | Maigret | Relatórios estruturados |
| Exposição Passiva | Holehe | Validação passiva de identidades |
| Exposição Passiva | SocialScan | Verificação pública de usernames |
| Attack Surface | theHarvester | Enumeração passiva de ativos |
| Attack Surface | Sublist3r | Enumeração de subdomínios |
| Conformidade | Nmap | Auditoria defensiva rápida |
| Metadados | ExifTool | Extração e sanitização documental |

## 🔍 Funcionalidades

- Enumeração passiva de subdomínios
- Auditoria rápida de serviços expostos
- Verificação pública de identidades
- Organização automatizada de relatórios
- Extração de metadados
- Provisionamento automatizado do ambiente
- Compatibilidade multi-distribuição Linux

## 📦 Instalação

1. git clone https://github.com/albertofilho-cy/Thyrus-OSINT.git  
2. cd Thyrus-OSINT  
3. chmod +x install.sh  
4. ./install.sh  

---

## ▶️ Execução

1. source .venv/bin/activate  
2. python3 thyrus.py
